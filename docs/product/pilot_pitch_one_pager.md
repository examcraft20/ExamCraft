# ExamCraft Pilot Program Invitation

**Smarter Exam Management. Built for Indian Education.**

## Overview
ExamCraft is a multi-user platform for building question banks, auto-generating papers, and managing approval workflows with print-ready PDF exports.

## Pilot Features (Free, 30 Days)
- **Question Bank**: Manual entries + Excel bulk import.
- **Paper Intelligence**: Pattern blueprints and auto-generation.
- **Global Library**: Pre-built CBSE and University templates.
- **Workflows**: Tracked lifecycle (Draft → Publish).
- **Export**: Branded institution PDFs.

## Requirements
- 30 days of active use by at least 3 faculty.
- Generate at least 2 real exam papers.
- Provide feedback via surveys and a debrief call.

## Security & Compliance
- **Data Residency**: Mumbai (ap-south-1).
- **Compliance**: Fully aligned with India's DPDP Act 2023.
- **Isolation**: Tenant-level data security with no third-party AI sharing.
